One 1024×1024 newspaper front page that sums up the world's news of Thursday 19 November 2026: 48 stories — 4 illustrated heroes (the Shenzhen trilateral summit, the ICJ genocide ruling, GTA VI launch day, Anthropic's record IPO), 12 illustrated cards, a UTC timeline strip, an attribution chip on every hero and card, a dotted world map with numbered pins, and 32 one-line briefs — drawn programmatically with Python + Pillow. Every letter is rendered by code; no AI-generated text appears in the image. A date-check line names the stories deliberately left out because they were not 19 November news.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
